**Teal Mask Ogerpon Box**
- Game plan: Grass-type "box" built around Teal Mask Ogerpon ex's Teal Dance
  (free Grass-energy attachment/acceleration), backing up one or more support
  attackers (community lists vary: some run all three Ogerpon masks, some pair
  Teal Mask with Mega Kangaskhan ex — "Slop Box").
- Biggest strength: fast, flexible energy acceleration lets it punch above a
  one-Basic-type deck's normal speed.
- Biggest weakness: Grass Weakness ×2 to Fire is universal across every build;
  a real Fire matchup is a bad day by default.
- This week: unchanged — still not present in the repo at all (2nd week
  blocked), and no official/community signal this week names the user's exact
  personal build.

**Crustle Wall**
- Game plan: stall behind Crustle's Mysterious Rock Inn Ability, which
  prevents *all* damage from opposing Pokémon ex attacks outright.
- Biggest strength: hard-walls the ex-heavy decks that currently dominate
  Standard (Dragapult ex, Gardevoir ex, etc. — nearly the whole S/A tier runs
  ex attackers).
- Biggest weakness: Mysterious Rock Inn only blocks *ex* damage — any
  non-ex attacker, or a deck built to avoid needing its ex Pokémon to attack,
  walks straight through it.
- This week: a real, already-written 60-card Crustle recipe exists — but it's
  sitting in **open PR #30** (`feature/grass-meta-fire`, unmerged against
  `main`), not on `main` itself. See §f.
