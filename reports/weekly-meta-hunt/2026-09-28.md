## e. Ogerpon Box — Proposed Adjustments

**No changes warranted this week — but this is the first week that conclusion rests
on actual in-repo sim evidence rather than "nothing concrete surfaced."** The
Baltimore-winning "Basic Box" archetype (§b/§c) shares nearly its entire Pokémon
core and Trainer/Tool/Stadium suite with `DECK_OGERPON_BOX` already in this repo —
it is, functionally, the same deck under a different name, already built. Two
specific, evidence-backed swap hypotheses drawn directly from this week's research
were built as one-line variants of `DECK_OGERPON_BOX` and gauntlet-tested with
`cli.py`'s `run`/`run_recipe` (greedy pilot, mirrored seats, seed 2026, pool rebuilt
fresh this session via `fetch_standard_pool.py`) against `dragapult`,
`mega_excadrill`, `gardevoir`, and `crustle_modern`:

1. **Ratio flip** (Teal Mask Ogerpon ex 4→2, Mega Kangaskhan ex 2→4 — matching
   Kasturi's own Kangaskhan-forward emphasis, everything else held identical),
   n=80/matchup:
   ```
                    baseline   variant(4 Kang/2 Oger)
   dragapult          60.0%          57.5%
   mega_excadrill     23.8%          20.0%
   gardevoir          35.0%          26.2%
   crustle_modern     16.2%          16.2%
   mean               33.75%         29.975%
   ```
   Flat-to-worse in every cell, worst on `gardevoir` (−8.8pt). Not pursued further.
2. **Supporter swap** (drop the 1 N's Plan, add 1 Crispin — the one clear Trainer
   difference from §c's second Basic Box list), re-run at n=200/matchup for a
   steadier read after a noisier n=80 pass looked promising:
   ```
                    baseline (n=200)   variant (n=200)
   dragapult             64.0%              63.0%
   mega_excadrill        28.0%              32.0%
   gardevoir             39.0%              36.5%
   crustle_modern        15.5%              17.5%
   mean                  36.625%            37.25%
   ```
   A +0.6pt mean swing, well inside sampling noise at this n (mixed by matchup, not
   a clean win). **Conclusion: neither isolated swap earns a decklist edit under
   this repo's own greedy-piloted engine.** The honest reading is that Kasturi's
   result may be piloting skill and/or the *combination* of changes (ratio + full
   Crispin/Cyrano package + Meowth count), not any single swappable card — worth
   retesting as a combined package next session (§g item 3), but a single-variable
   swap is what this project's own rule requires before editing `decks.py`, and
   single variables didn't move the needle here.
