## Headline: a repo-health regression, not a meta story

Before anything meta-related could be measured, the standalone test suite had to be
run — and it wasn't clean. `data/standard_pool.json` is gitignored and rebuilt fresh
each session; rebuilding it this time exposed **three real, pre-existing bugs**, not
caused by this scan but newly surfaced because nobody had rebuilt-and-tested the
pool end-to-end since at least August:

1. **`cli.py --futures` and `--list` were both broken.** A local
   `from src.engine.decks import DECKS` inside the `--futures` branch made Python
   treat `DECKS` as a function-local name for the *entire* `main()` function,
   breaking `--list` (and anything else reading the module-level `DECKS`) whenever it
   ran in the same process before `--futures`. Fixed by deleting the redundant local
   import (the module-level import at the top of `cli.py` already covers it).
2. **A silent print-collision regression in `data/manual_cards.json` broke
   `mega_excadrill`'s actual engine.** The manual supplement pinned bare `"Drilbur"`
   to the PBL 46 print (Call for Family / Dig Claws — the real tournament-list
   card). `fetch_standard_pool.py`'s merge logic skips any manual card whose **name**
   already appears in the upstream dump, on the documented assumption that "upstream
   shipping the name" means "upstream shipping the same card." That assumption broke
   the moment upstream's mark-H legality window started including the *Temporal
   Forces* "Drilbur" (sv5-85, Dig Dig Dig / Sand Spray) — a different, same-named
   print. The manual override was silently discarded and `mega_excadrill` /
   `mega_excadrill_shaymin` were quietly playing a Drilbur that doesn't have Call for
   Family at all, which is exactly the failure `tests/test_mega_excadrill_deck.py`'s
   Kieran check caught. Fixed per this project's own established print-collision
   convention: the manual PBL print is now named `"Drilbur (PBL)"`, bare `"Drilbur"`
   is left to resolve to whatever upstream provides (now the TEF 85 print, which
   already had its own effect implementation waiting under the stale key
   `"Drilbur (TEF)"` — renamed to bare `"Drilbur"` to match). Updated:
   `data/manual_cards.json`, `src/engine/decks.py` (`DECK_MEGA_EXCADRILL`,
   `DECK_MEGA_EXCADRILL_SHAYMIN`), `src/engine/effects.py` (3 registry keys),
   `tests/test_dig_dig_dig.py`, `tests/test_metagross_cri_drilbur_pbl.py`.
3. **Five committed decks/tests referenced cards that had never actually been added
   to `data/manual_cards.json`**, despite `effects.py` already carrying full, real,
   tested implementations for all of them (`_jetting_blow`, `_nebula_beam`,
   `_telepathic_on_attach`, `_powerful_hand`, `_psychic_draw`) — this was a pure
   data-layer gap, not a logic bug. Added, with real card text/stats sourced this
   session: **Staryu** (me3-20, Perfect Order), **Mega Starmie ex** (me3-21, Perfect
   Order — Jetting Blow / Nebula Beam), **Telepathic Psychic Energy** (me3-88,
   Perfect Order), and **Alakazam** (me1-56, Mega Evolution — Psychic Draw /
   Powerful Hand), the last added as `"Alakazam (MEG)"` since upstream's bare
   `"Alakazam"` is a different, unrelated SV-era print (sv6-82, Strange Hacking) —
   same print-collision convention as (2). Updated `src/engine/effects.py` (2
   registry keys) and `src/engine/decks.py` (`DECK_ALAKAZAM`), plus
   `tests/test_alakazam.py`, `tests/test_chienpao.py`, `tests/test_clefairy.py`.

**Net effect: 12 of 102 test files went from failing to passing.** Full suite status
after fixes: 99/102 pass. The 3 remaining failures are `test_arena.py` and
`test_train.py` (both `ModuleNotFoundError` for `torch`/`numpy` — an optional ML
subsystem outside the deterministic engine, environment-only, not a code bug) and
`test_toucannon_deck.py` (one rare live-fire line — Area Zero Underdepths' Bench
shrink clause — never fires across its 40 fixed seeds under the refreshed pool; the
underlying logic is independently proven correct by `tests/test_area_zero_underdepths.py`,
which passes cleanly, so this reads as incidental AI-pathing drift from the pool
refresh rather than an engine defect; flagged for a follow-up seed/sample check, not
fixed this scan). `tests/test_determinism.py` passes — the determinism invariant
held throughout.

**Why this matters for every number this project has quoted since August:** if
nobody rebuilt the pool and ran the suite in between, `mega_excadrill`'s own ladder
and gauntlet numbers in `docs/LADDER_LOG.md` / `docs/META_GAUNTLET_2026-08.md` were
measured *before* this regression could have existed (the fetch/mark-legality
interaction is new), so they are not retroactively suspect — but it's a reminder that
this scan's own "full standalone test suite green" gate is load-bearing, not
ceremonial.

## Build-bar: one archetype crossed it, deferred rather than rushed

**N's Zoroark ex / Pecharunt ex** clears the bar comfortably and has for a while:
~5.0–5.4% metagame share across the sources checked this session (dittobase.com:
5.40% share / 47.79% WR over 519 events, last played 2026-09-15; `docs/META_GAUNTLET_2026-08.md`
already had it at 5.16% in August), making it a persistent top-8 archetype with
**zero faithful representation in the registry** — the only prior artifact
(`decks/imported/n_zoroark.json`, referenced in the August gauntlet doc) does not
exist in the current checkout, and even when it did it was an un-scripted import
with no effects, which is why that gauntlet run flagged its 93.3% sim result as
"combo mispiloting," not a real measurement.

All four required cards are real, Standard-legal, and already in the pool:
**N's Zoroark ex** (sv9-98, mark I — "Night Joker": choose one of your Benched N's
Pokémon's attacks and use it as this attack; "Trade" ability: discard a card to draw
2), **Zoroark** (sv6pt5-32 — Illusory Hijacking scales with opposing ex/V count),
**Pecharunt** (svp-129) and **Pecharunt ex** (sv6pt5-39 — Subjugating Chains
pivot-and-poison). **Deliberately not built this scan.** Night Joker is a genuinely
new engine primitive — "copy a different in-play Pokémon's attack, including
whatever cost/effect that attack carries, restricted to a named sub-family
('N's X') of Benched Pokémon" — and faithfully scripting plus testing that, on top
of sourcing a real tournament decklist for which other "N's" attackers it plays,
is more than a same-day addition can responsibly cover without risking exactly the
half-finished, undertested implementation this project's conventions forbid.
**Recommending it as next scan's top build priority**, explicitly flagged two scans
running now (Aug gauntlet, this scan) rather than silently dropped.

No other unrepresented archetype could be confirmed crossing the 2% bar this
session: Ceruledge, Sharpedo Toxtricity, Mew Box, and Ogerpon/Meganium (Victor
Carreira Rodrigues' 1st-place Recife list — a *different*, evolution-engine Ogerpon
pairing from this registry's `ogerpon_box`, per `reports/weekly-meta-hunt/2026-10-12.md`
§b/§e) each surfaced at exactly one event this window with no share percentage
behind them — below this skill's evidence bar for a build, logged as watch items.
