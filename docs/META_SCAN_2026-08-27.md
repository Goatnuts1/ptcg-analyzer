Second run of the weekly meta-scan procedure. Baseline: `docs/META_SCAN_2026-08-20.md`.

## Blocker: the live meta table was unreachable this scan

Both `play.limitlesstcg.com` and the bare `limitlesstcg.com` domain returned
`EGRESS_BLOCKED` from this session's network proxy — an organization-level egress
denial (per `/root/.ccr/README.md`: "do not retry or route around it — report the
blocked host"), not a transient failure. No fresh share/real-WR table could be
pulled this week. Per CLAUDE.md's calibration rule, **no win-rate or share number
below is fabricated** — everything under §Meta drift is either carried forward
unchanged from 2026-08-20 or corroborated from a secondary source, and it is
labeled which.

This is a real gap, not a formality: it means step 2 (diff shares, find risers) and
the "build bar" check (≥2% share, or rising twice) could not be evaluated against
fresh data this week. **No archetype crossed the build bar this scan — because the
bar itself could not be measured.** Next scan should retry the fetch before
concluding anything about drift.
