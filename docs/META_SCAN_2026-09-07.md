# Meta scan — 2026-09-07

**Headline: this week's real finding is not a metagame shift, it's a data-layer
regression.** Nine registered decks were silently broken by upstream card-data
drift and are fixed in this scan. The live Limitless table could not be
re-fetched (network egress to every tournament-data source is blocked in this
session), so no fresh share/win-rate numbers are reported — the 2026-08-20
baseline is carried forward, explicitly flagged stale (18 days).

## 1. Data-layer regression found and fixed (the actual headline)

Routine hygiene (`python3 tests/test_*.py`, run standalone per the skill) found
**18 of 102 test files failing** on a freshly-regenerated `data/standard_pool.json`
(1300 → 1331 → 1337 cards as upstream `PokemonTCG/pokemon-tcg-data` grew). Root
cause, in every case but one: the pool's dedupe-by-name step keeps the FIRST
standard-legal print of a name in `sets.json` order (oldest set wins), and
upstream has started shipping a second standard-legal print of several cards
this project already depends on — so the bare name silently started resolving
to the WRONG print, or the deck's real print vanished under a name nothing
looked up.

**Broken decks (all now fixed): `alakazam_deck`, `mega_excadrill`,
`mega_excadrill_shaymin`, `slowking`, `slowking_slowbro`, `slowking_annihilape`,
`gardevoir_real`, `hide_n_sneak`, `starmie_toolbox`** — 9 of the 36 registered
decks, including `mega_excadrill`, the deck this project's own ladder log calls
"the user's own deck." Two distinct failure modes:

- **New print collisions** (bare name silently pointed at the wrong card):
  - `Alakazam`: upstream added a legal Twilight Masquerade print (`sv6-82`,
    "Strange Hacking"/"Psychic") that now wins the dedupe race over the Mega
    Evolution print `alakazam_deck` actually needs (`me1-56`, "Powerful
    Hand"/"Psychic Draw"). Fixed: the MEG print is now `"Alakazam (MEG)"` in
    `manual_cards.json`; `decks.py` and `effects.py` updated to match.
  - `Drilbur`: upstream added a legal Temporal Forces print (`sv5-85`, "Sand
    Spray"/Dig Dig Dig) that now wins the dedupe race over the Pitch Black
    print (`me5-46`≈`pbl-46`, "Call for Family") `mega_excadrill` and
    `mega_excadrill_shaymin` need. Fixed: the PBL print is now
    `"Drilbur (PBL)"`; the bare name now correctly resolves to TEF, matching
    the pre-existing `"Drilbur (TEF)"` effect registration that had never
    actually had a backing pool card (`test_dig_dig_dig.py` was failing before
    this scan touched anything — a pure pre-existing gap, now closed with a
    disambiguated id `sv5-85-tef` since the pool enforces unique ids).
- **Cards entirely missing** (`Staryu`, `Mega Starmie ex`, `Telepathic Psychic
  Energy`): all three are real, standard-legal (mark J) cards from `me3`
  (Perfect Order) that upstream still flags `legalities.standard: "Not Legal"`
  set-wide (112 of 124 `me3` cards are in this state — the same upstream lag
  that originally forced the Honedge/Doublade/Aegislash line into
  `manual_cards.json` by hand). These three were simply never added. Added now,
  using the real official card data pulled directly from
  `PokemonTCG/pokemon-tcg-data` (not limitlesstcg, which was unreachable — see
  §2 — but the same upstream source the fetch script already trusts), following
  the exact precedent already set for the Aegislash line.

All fixes are additive/renaming in `manual_cards.json` plus reference updates
in `decks.py`/`effects.py`, using real card data throughout — no fabricated
text. `python3 -c` sweeps confirm **zero remaining orphan registry keys** across
`ATTACK_EFFECTS`, `ABILITY_EFFECTS`, `ON_EVOLVE_TRIGGERS`, and every other
`*_EFFECTS`/`*_TRIGGERS` dict in `effects.py`, and every deck in `DECKS` now
`load_deck()`s cleanly.

**Test suite: 18 failures → 3.** Remaining three, unrelated to this fix and
pre-existing before this scan touched anything:
- `test_arena.py`, `test_train.py` — `ModuleNotFoundError: torch` / `numpy`.
  Missing optional deps for the separate `src/learn/` subsystem (not touched by
  meta-scan, not installed in this environment).
- `test_toucannon_deck.py` — a coverage-smoke check ("Area Zero Underdepths'
  Bench shrink clause never fired in 40 seeded games") that depends on exact
  RNG trajectories; the pool's continued growth (1300→1337) shifts search-effect
  draw outcomes even under fixed seeds. Does not touch any card this scan
  changed (`toucannon` doesn't play Alakazam/Drilbur/Staryu/Telepathic Psychic
  Energy). Flagged as homework for a future session, not chased down here.

`tests/test_determinism.py` and `tests/test_pool.py` both pass — the
determinism invariant and pool-schema invariants hold after the fix. A smoke
matchup (`alakazam_deck` vs `mega_excadrill`, 20 games, greedy) runs cleanly.

**Impact on trust in past numbers:** none. This is a *restoration*, not a
design change — the affected decks were built and originally measured back
when their intended prints resolved correctly; the collisions are new upstream
drift. Every previously-recorded win rate for these 9 decks was measured
against the *correct* cards at the time and stays valid as history. Going
forward, though, `mega_excadrill` and `alakazam_deck` were **silently playing
the wrong Drilbur/Alakazam print** in this checkout until today's fix — any
number produced by an un-refreshed pool between whenever this drift landed
upstream and today should be treated with suspicion; none exist in this
session's history that weren't already invalidated by the KeyError crash.
