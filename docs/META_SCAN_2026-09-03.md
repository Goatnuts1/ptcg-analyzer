## Data-layer finding: the pool was silently broken from a clean fetch

Rebuilding `data/standard_pool.json` from scratch (`python3
src/fetch_standard_pool.py --out data/standard_pool.json` — needed regardless,
since it's a gitignored generated artifact) surfaced **19 of 102 test files
failing** against the freshly-fetched pool. Root causes, both upstream-drift
bugs, not code regressions:

1. **`is_standard_legal()`'s belt-and-suspenders check was stale for a whole
   set.** It required the upstream dump's own `legalities.standard == "Legal"` in
   addition to a legal regulation mark. As of this scan that field flags **112 of
   "Mega Evolution — Perfect Order" (me3)'s 124 mark-J cards "Not Legal"** —
   including Mega Starmie ex and Telepathic Psychic Energy, both real,
   tournament-played Standard cards (Perfect Order released 2026-03-27, five
   months ago). And per the rotation announcement above, Standard currently has
   **zero** individually banned cards, so the check had no real bans left to
   catch and was pure false-negative risk. Fixed: mark-only now (see CLAUDE.md
   for the full reasoning and the reversibility note if a real ban ever shows up).
2. **Four print collisions**, the same shape as the project's existing
   `Metagross (CRI)` / `Shuppet (PBL)` convention but newly triggered because
   upstream started shipping a same-named-but-different print: `Drilbur` (manual
   = Pitch Black `pbl-46`, Call for Family; upstream now also ships Temporal
   Forces `sv5-85`, Dig Dig Dig, processed earlier in fetch order), `Alakazam`
   (manual = `me1-56`, Powerful Hand; upstream now also ships `sv6-82`, Strange
   Hacking, processed earlier), `Rocky Fighting Energy`/`Telepathic Psychic
   Energy` (upstream's Energy-supertype JSON never carries a `types` field at
   all — what a Special Energy provides lives only in free-text `rules` — so
   upstream's copy would silently zero out `provided_types()`), and `Staryu` (a
   same-print fixup: upstream's copy has an empty `evolvesTo`, cosmetic only).
   Fixed via a new `PRINT_OVERRIDES` set in `fetch_standard_pool.py` that keeps
   the manual entry authoritative for these five names even after upstream ships
   the same bare name; `Drilbur (TEF)` is a new, independent manual entry for the
   Dig Dig Dig print so both stay reachable. `data/manual_cards.json` grew from
   29 to 33 entries.

**Result: 98/102 test files green** (up from 83/102 on the first clean fetch, before
any fix). The remaining 4: `test_arena.py`/`test_train.py` need `numpy`/`torch`
for the optional `src/learn/` subsystem, which isn't in `requirements.txt` and is
out of scope here; `test_doublade_deck.py`/`test_toucannon_deck.py` are narrow
existence-checks over a small fixed seed sample (30/40 seeds) that happened to
miss a rare trigger after the pool changes shifted RNG trajectories elsewhere —
verified benign by rerunning both with 150 seeds (both pass; the underlying
effects fire and behave correctly, it's a sampling-luck artifact of the small
window, not a broken interaction). Not changed, since widening a test's `SEEDS`
constant is a call for whoever owns that test's statistical-confidence bar, not
this scan.

Pool size moved from 1,331 to 1,399 cards from the legality fix alone (many more
real "Perfect Order" cards now correctly included). CLAUDE.md's data-layer
section is updated with the full reasoning, including the reversibility note.
