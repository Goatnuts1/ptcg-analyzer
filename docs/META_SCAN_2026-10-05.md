## 1. Critical engineering finding, fixed this scan: a live print-collision regression
broke the user's own house deck

Independently of the PR backlog, a full fresh-pool test run surfaced a second, more
serious bug that PR #46 had found but deliberately **not** fixed (judged too risky to
blind-fix in an unattended run): **the upstream card dump started shipping its own
`"Drilbur"` and `"Alakazam"` under those bare names**, colliding with this project's own
manual-supplement prints of the same name:

- `"Drilbur"` used to resolve to the Pitch Black tournament-list print (`pbl-46`, Call
  for Family / Dig Claws) that `mega_excadrill` and `mega_excadrill_shaymin` are built
  around. Upstream's own `Drilbur` (`sv5-85`, Temporal Forces, the "Dig Dig Dig" print)
  now wins the bare name instead — **the project's own flagship deck was silently
  simulating the wrong card.**
- `"Alakazam"` used to resolve to the MEG print (Psychic Draw / Powerful Hand) that
  `alakazam_deck` needs. Upstream's own `Alakazam` (`sv6-82`, "Strange Hacking") now wins
  instead, breaking that deck the same way.

**Fixed, following this project's own print-collision convention exactly**: renamed the
tracked manual entries to `"Drilbur (PBL)"` / `"Alakazam (MEG)"`, updated `decks.py` (both
Mega Excadrill lists, `alakazam_deck`) and the `effects.py` registry keys to match, and —
since upstream's bare `"Drilbur"` turns out to BE the TEF "Dig Dig Dig" print the project
had separately tracked as `"Drilbur (TEF)"` — swapped that registration to the bare name
too, so it stops being dead code. 6 test files needed the same rename
(`test_alakazam.py`, `test_chienpao.py`, `test_clefairy.py`, `test_dig_dig_dig.py`,
`test_metagross_cri_drilbur_pbl.py`, plus the Staryu/Starmie/Telepathic Energy data-gap
fix). **Full standalone suite: 103 files, 100 green** — the only 3 failures are the
documented pre-existing ones (`test_arena.py`/`test_train.py` need `torch`/`numpy`, not
installed in this environment; `test_toucannon_deck.py`'s seed-dependent flake). Determinism
invariant (`test_determinism.py`) still holds.

**A third, unrelated one-line bug, found while sanity-checking the new deck shows up in
the CLI**: `cli.py --list` crashed (`UnboundLocalError` on `DECKS`) because the
`--futures` branch's redundant local `from src.engine.decks import DECKS` made `DECKS`
local to all of `main()` — a classic Python scoping gotcha, since `DECKS` is already
imported at module level. Removed the redundant local import.

**A second, unrelated bug found and fixed while debugging the new deck below**: Kofu's
`can_play` guard checked `len(hand) >= 2`, but its effect (bottom 2 OTHER cards, draw 4)
runs AFTER `play_trainer` already pops Kofu itself from hand — so it needed `>= 3`, not
`>= 2`. The off-by-one meant that whenever a hand settled at exactly `[Kofu, X]`,
`can_play` said yes, the effect's own `len(hand) < 2` said no, and the card went back to
hand to be re-offered identically forever — an infinite, non-turn-ending loop. Any deck
that can reach a 2-card hand holding Kofu could hit this; `ns_zoroark`'s Item-heavy hand
cycling reaches it reliably. Fixed (`>= 3`).

## 3. Build: N's Zoroark ex (`ns_zoroark`)

**Crosses the build bar by a wide margin on every reading available.** This project has
had evidence this archetype is real and sizeable since the 2026-08-17 calibration
gauntlet (`docs/META_GAUNTLET_2026-08.md`: 5.16% share, 48.14% real win rate — flagged
there as "93.3% sim, combo mispiloting" because, as this scan confirmed, **it had zero
registered effects at all**, not even the card's signature Ability/attack; the 93.3% was
Pokémon trading on printed stats with none of its actual text implemented). This scan's
WebSearch pass corroborates it's still live and plausibly larger now (6.2-10% across
different trackers, "Tier 2", 9th/11th/12th/14th/16th/26th at Worlds 2026 across multiple
independent pilots, an online tournament win).

**Provenance**: Michele Schiraldi, 26th place, World Championships 2026 (Limitless list
28773; corroborated via WebSearch, direct Limitless fetch blocked — see §2's access note).
A Worlds Top-8 list (Öjvind Svinhufvud, 9th) runs the same 19 Pokémon and a near-identical
Trainer line, which cross-checks the decklist. All 27 unique cards were already in
`data/standard_pool.json` under real text — **no new `manual_cards.json` entries needed**,
only effects.

**Engine (§META-2026-10 in `effects.py`)**: Trade (discard 1, draw 2 — an Ability, same
discard-then-draw shape as Klefki's Stick 'n' Draw attack); Night Joker, which needed a
genuine new mechanic — "choose 1 of your Benched N's Pokémon's attacks and use it as this
attack" — implemented as a new `Action.copy_attack_index` field, enumerated in
`game.legal_actions` as one action per (benched N's Pokémon, one of its attacks) pair
(excluding that Pokémon's own Night Joker, closing the self-recursion case), threaded
through `_resolve_attack` via `ctx.target`, and run through the SAME
`ATTACK_EFFECTS`/`ATTACK_EFFECT_OWNS_DAMAGE`-aware dispatch Slowking's Seek Inspiration
already established for "use it as this attack" semantics (the copied effect's own
costs/riders genuinely fire; Weakness/Resistance still key off the COPIER's type). Per
CLAUDE.md's chokepoint checklist, this new action shape got its own `mcts._semantic_key`
case (without it, every Night Joker choice collapses into one key and silently vanishes
from search — exactly the bug class `tests/test_mcts_keys.py` exists to catch; added
`(ns_zoroark, mega_excadrill)` to that test's pairing sweep).

N's Zekrom's Shred (ignore_active_effects, same chokepoint flag as Superb Scissors) and
Rampaging Thunder (250, then `pending_cannot_attack` — the Blood Moon/Metal Slash
pattern); N's Darmanitan's Back Draft (variable ×30 per Basic Energy in the opponent's
discard) and Flamebody Cannon (90 engine-applied + discard its own Energy + 90 to the
weakest bencher, the Jetting Blow snipe policy); Pecharunt ex's Irritated Outburst (60×
prizes the opponent has taken) and Subjugating Chains (switch in a Benched Darkness
Pokémon — **the card's own Poison rider is logged, not applied: this engine does not
model Poison, same documented gap as Numbing Water's Paralysis**); Transformation Tome
(the "play 2 at once" Item — the effect function itself finds and removes the second
copy, since the generic `play_trainer` flow only pops one, then swaps a Basic from the
discard pile into a live board slot, keeping that slot's damage/energy/turns-in-play
intact); N's PP Up (any-number-per-turn Item, attach a Basic Energy from discard to a
Benched N's Pokémon); Black Belt's Training (+40 vs. the opponent's Active ex, reusing
the existing `bonus_damage_vs_ex_v` turn-scoped flag); N's Castle (a new passive Stadium —
N's Pokémon in play, both sides, have no Retreat Cost — added at the one chokepoint,
`game.retreat_cost`). **Binding Mochi** is a legal, attachable Tool but its own bonus
(+40 vs. the opponent's Active, gated on the HOLDER being Poisoned) can never fire in this
engine for the same reason as Subjugating Chains — a known, honestly-logged limitation,
not a bug.

**Pilot note (read before quoting any win rate for this deck)**: greedy mispilots this
deck severely — three real issues were found and fixed (none of them card-specific
hacks): (1) `GreedyAgent` evaluated every Night Joker option at its printed damage (0),
so it never recognized a lethal copied Rampaging Thunder — fixed with a `seek_value`-based
`_night_joker_value` branch, the same shape as the existing Do the Wave / Seek Inspiration
exceptions; (2) greedy's blanket "evolve whenever possible" priority evolved every single
Benched N's Zorua into another N's Zoroark ex the instant one existed, which strands the
WHOLE BOARD with zero legal attacks the moment no other "N's" Pokémon is left to copy —
fixed with a narrow guard that holds back exactly the evolve that would strand the last
copy source (the first Zoroark ex still evolves immediately); (3) `Subjugating Chains`'
`can_use` guard was too permissive and fired on literally every legal turn, thrashing a
perfectly good Active out for a random benched Darkness Pokémon 20+ times in a single
19-turn game — fixed by requiring the current Active to actually be unable to attack
AND a benched candidate to actually be able to. Even after all three fixes, **greedy still
reads ~3% across every opponent tested (colorless, mega_excadrill)** — this is the
documented "greedy mispilots complex/combo decks" ceiling (CLAUDE.md), just worse than
`raging_bolt`'s 16-28%, because the deck's whole plan (hold Trade/Night Joker fuel,
sequence Transformation Tome recycling, bait with Subjugating Chains) is multi-turn
value play greedy's single-decision heuristics can't express at all.
